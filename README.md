# BSTFA
Bayesian Spatio-Temporal Factor Analysis

R functionality for fitting and visualizing a Bayesian spatio-temporal factor analysis model for modest-sized spatio-temporal data.  

Primary Reference: Extension of methods developed in Berrett, et al (2020), https://doi.org/10.1002/env.2609 

Prior Art: First implementation within R of (adapted) algorithms implemented in research articles.
